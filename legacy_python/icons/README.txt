Placez ici le fichier FileCleaner.ico (icone officielle de l'application).

Il sera automatiquement utilise pour :
- la fenetre de l'application (ui/app.py, methode _apply_icon)
- l'executable et la barre des taches lors de l'empaquetage (voir build.py)

Format recommande : .ico multi-resolutions (16x16, 32x32, 48x48, 256x256).
